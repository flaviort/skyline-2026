# Skyline 2026

Website for The Skyline Agency, Dallas TX. Next.js 16, TypeScript, Tailwind CSS 4, GSAP and Lenis.

## Getting started

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:3000.

## Docs

All documentation (product, plan, specs, architecture, reference, content, and later the design system) lives in `docs/`. Start at `docs/README.md`.
