# Page: Project (`/work/[slug]`)

Status: spec
Approved by / date:

One template for every case study, fed entirely by the exported data. Old `/project?<slug>` URLs redirect here.

## Reference (`/werk/p-van-der-niet`)

| Section | What it does |
|---|---|
| Case steps | Split screen. Left half (light): service label, client name as a fitted headline, a one-line promise in the serif, then paragraphs of story that scroll normally. Right half: a sticky panel in the project's color with media (image or video) that changes as each text step reaches the middle of the viewport. The menu is replaced by a back arrow button top right. |
| Case end | "The result?" line, then a full-width video player with controls |
| More work | "MORE WORK" headline and three project cards (same card as the work grid) with hover video and cursor marquee |
| Contact CTA and footer | Shared |

## Skyline version

The exported WordPress data has, per project: title, subtitle, description, services, industries, year, website URL, color, cover, and about 12 content blocks of 8 types (`title-desc`, `big-element`, `fs-element`, `grid`, `marquee`, `two-blocks-full`, `slider`, `expanding-grid`).

| # | Part | Content | Components |
|---|---|---|---|
| P1 | Case steps | Left: services label, client name (fitted headline), subtitle in the serif, then one step per `title-desc` block. Right: sticky panel in the project color with the step's media (the following `big-element` or `fs-element`). Back button to `/work`. Meta row: year, industries, services, "Visit website" link. | `StickySteps`, `HeadingFit`, `Media`, `IconButton` |
| P2 | Gallery blocks | The remaining blocks in order, each rendered by its block component: grids, sliders, marquees, two-up images, expanding grids, full-screen images | `ProjectBlocks` and the 8 block components |
| P3 | Result | Closing line plus the best video, if the project has one; otherwise a full-width still | `Media` with controls |
| P4 | More work | Next 3 projects, same cards as the work grid | `ProjectCard` `variant="grid"`, `CursorMarquee` |
| P5 | Contact CTA and footer | Shared | `ContactCta`, `Footer` |

Project colors are used for the sticky panel only when text on them passes contrast; otherwise the panel uses the nearest palette color.
