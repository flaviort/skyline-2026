# Architecture

How the codebase is organized and the rules every change follows. Read with `AGENTS.md` (Next 16 ships breaking changes; check `node_modules/next/dist/docs/` before using an API from memory).

## Stack

| Layer | Choice | Version |
|---|---|---|
| Framework | Next.js App Router, React Server Components by default | 16.3 |
| Language | TypeScript, strict | 5 |
| Styling | Tailwind CSS 4 (CSS-first config in `globals.css`) | 4 |
| Animation | GSAP with ScrollTrigger, SplitText, DrawSVGPlugin, InertiaPlugin, CustomEase; `@gsap/react` for `useGSAP` | 3.15 |
| Smooth scroll | Lenis via `lenis/react` | 1.3 |
| 3D | three.js 0.186 through React Three Fiber 9 (`useLoader` with three's own `GLTFLoader` and Meshopt decoder; no drei). Models optimized with `gltf-transform` (`npm run model:nova`). Loaded lazily, only on pages that render Nova. | added in part 01 |
| Fonts | `next/font/google`, self-hosted at build: Inter Tight only (variable weight 100 to 900; D15) | |
| Page transitions | Custom GSAP overlay (DrawSVG stroke) driven by a `TransitionLink` and the router, replacing the reference's Barba | |

All GSAP plugins are free since 3.13, so nothing here needs a club license.

## Content and data

The site is fully static: no WordPress, no database, no CMS at runtime.

- **Projects** come from a one-time export. `scripts/export-wordpress.mjs` calls the old endpoints (`get_all_projects`, `get_project&name=<slug>` on `wp.theskylineagency.com`), downloads every image and video into `public/images/work/<slug>/`, and writes `src/content/projects/<slug>.ts` with a typed `Project` object: title, slug, subtitle, description, services, industries, year, url, color, cover media, and the content blocks (`title-desc`, `big-element`, `fs-element`, `grid`, `marquee`, `two-blocks-full`, `slider`, `expanding-grid`). The output is committed; after that the WordPress site can be switched off. The script runs during part 4.
- **Everything else** (copy, nav, services, contact details) is typed TypeScript in `src/content/`.
- Editing content means editing those files and redeploying. If non-developers need to edit later, a file-based CMS can sit on top of the same files without changing the pages.
- **Contact form** (internal page) is the only dynamic piece: a route handler that sends email through one `sendMail` adapter (Resend while testing, SendGrid in production). Keys in Vercel environment variables. No storage.
- **Consent**: the cookie choice lives in the visitor's `localStorage`; analytics and marketing scripts load only after consent.

## Placeholders from the reference

Media or stickers taken from extrafazant.nl for development go in `public/_ref/` only. The folder is gitignored, so nothing in it can be committed or deployed from git. Each file is listed in the placeholder register in `docs/CONTENT.md`. A pre-launch check fails if any source file references `/_ref/`.

## Rules

**Server first.** Sections are Server Components that render real HTML. Motion lives in small client components that wrap server-rendered children, so the page reads fine with JavaScript off.

**One GSAP entry point.** Import `gsap`, `ScrollTrigger`, `SplitText` and friends from `@/lib/gsap`, never from `gsap` directly. Use `useGSAP` with a scope ref so every tween and ScrollTrigger is reverted on unmount.

**Visible by default.** No element ships with `opacity: 0` in CSS. Hidden initial states are set by GSAP right before animating, so a failed script leaves content readable.

**Reduced motion.** Wrap motion in `gsap.matchMedia()` with a `(prefers-reduced-motion: no-preference)` branch. The reduced branch shows final states instantly. `SmoothScroll` already skips Lenis for reduced-motion users.

**Tokens only.** Colors, fonts and eases come from `@theme` in `globals.css`. No hex values in components. Sizes use rem (which scales with the fluid root) or the heading and paragraph utilities (`heading-xxl` to `heading-xxs`, `para-xl` to `para-xs`).

**Readable floor.** The fluid root can drop to 8px on a 992px-wide window. Paragraph utilities carry a pixel floor (`max(1rem, 14px)` and so on); keep that pattern for any new text style.

**Content out of components.** Copy, links and media paths live in `src/content/*.ts` with types, so later pages and a CMS can reuse them.

**Icons.** No icon library (Q20). Icons are inline SVG paths in one `Icon` component: the legacy set from `../skyline-2023/assets/svg/` (diagonal arrow, arrow down, angle down, close, file, volume, socials) plus a few drawn to match (menu, plus, minus, arrow right, up and back), one stroke weight, `currentColor`.

**Images.** `next/image` for every raster, with explicit `sizes`. Hero and first-viewport media get `priority`. Case-study video: short muted loops as MP4/WebM with a poster; long-form through a streaming host (decision pending).

**No development notes in shipped output.** Direction contracts and planning text stay in `docs/` and `.impeccable/`, never in JSX comments, data attributes or metadata.

## Component library

The site is built from a small set of reusable, prop-driven components. A section file should read like a composition of library parts plus content, not like a pile of one-off markup.

### Principles

- **One pattern, one component.** If the reference uses a pattern twice (it usually does), it is a component. Variation comes from props and variants, never from a copied file.
- **Look and behavior are separate.** Motion components (`WeightHover`, `TextReveal`, `Parallax`...) wrap any children and know nothing about content. Visual components (`Button`, `Frame`, `ProjectCard`...) know nothing about scroll or pointer logic. Sections combine the two.
- **Props take tokens, not hex.** The site is dark by default (`Section theme="dark"`); `theme="light"` opts a section into the ground. Color props are typed as the palette union (`"orange" | "ink" | "paper" | "ground" | "cobalt" | "visor" | "lilac"`). Components expose CSS custom properties (for example `--button-bg`) so a one-off override stays possible without a new variant.
- **Defaults are the reference.** Every tunable (radius, weights, durations, eases, stagger) defaults to the value measured in `docs/REFERENCE.md`, so a bare `<WeightHover>` already behaves like the original.
- **Shared plumbing lives in hooks.** One pointer tracker, one reduced-motion check, one fine-pointer check, one Lenis instance. Components subscribe; they never add their own global listeners.
- **Accessible by construction.** Split text keeps an `aria-label` with the full string; decorative layers are `aria-hidden`; every pointer-only effect has a keyboard or static path.
- **Extract, don't predict.** Build the component the part needs with the props the reference proves. Add props when a second use needs them, not before.
- **Variants helper.** `cn()` in `src/lib/utils.ts` is a dependency-free class joiner. Variant maps are plain typed records (see `ArrowChip`, `Heading`); no `cva` until a component genuinely needs compound variants.

### Component lab

`/lab` is a development-only route (returns 404 in production) that renders every library component with its variants. New components land there first, so you can review a button or a card on its own before it goes into a section.
